# Documents

One folder per milestone, in order. For each submission keep:

- the editable source (`.docx`, from the department Report Template),
- the exact PDF you submitted on Moodle,
- `CHANGES.md`: one line per feedback point and how you addressed it (each submission must reflect the previous feedback).

Large videos (demo recordings) go in the GitHub Release for that submission, not in the repo.
